# 횟수 카운터 (10_RepCounter)

운동 횟수를 세트 카드 단위로 세는 웹 앱. 운동을 저장해 두고, 오늘 할 운동만 체크해서 시작함.

## 사용 방법

1. **운동 목록**: `+ 운동 추가`로 이름·목표 횟수·세트 수를 저장. 행을 누르면 체크, 오른쪽 연필 버튼은 편집(순서 변경·삭제).
2. **시작**: 체크한 운동만 목록 순서대로 시작. 체크 상태는 다음에도 기억.
3. **운동 중**: 카드를 누르면 이번 세트 횟수만큼 증가. 옆으로 밀면 다음/이전 운동, 아래 탭을 눌러도 이동.
   - 되돌리기: 보고 있는 운동의 직전 세트만 취소(PC는 Ctrl+Z, ←/→로 운동 이동)
   - 한 운동을 끝내면 약 1초 뒤 아직 안 끝난 다음 운동으로 자동 이동
   - 그만하기: 운동을 끝내고 목록으로(센 횟수는 지워짐)
4. **완료**: 모든 운동을 끝내면 운동별 요약과 색종이.

진행 상황은 브라우저에 저장되어 앱을 닫았다 열어도 이어짐.

### 세트 나누기

분할 = 세트 수. 100개 4세트 → 25개 × 4. 나누어떨어지지 않으면 앞 세트부터 1개씩 더 줌(100개 3세트 → 34·33·33). 마지막 세트 카드는 주황색.

## 실행

### 휴대폰

주소: https://yuseungha.github.io/RepCounter/

GitHub Pages로 배포. PC가 꺼져 있어도 열림. 처음 한 번 홈 화면에 추가하면 앱처럼 실행 가능.

- iPhone(Safari): 공유 → 홈 화면에 추가
- Android(Chrome): ⋮ → 홈 화면에 추가

열 때 인터넷 연결 필요. 진행 상황은 휴대폰 브라우저에 저장되어 앱을 닫아도 유지.
`main`에 올리면 1~2분 뒤 같은 주소에 반영.

### PC

설치 없음. `index.html`을 브라우저로 열면 됨.

참고: 파일을 휴대폰에 복사해 여는 방식은 휴대폰 브라우저가 로컬 HTML·스크립트를 막는 경우가 많아 권장하지 않음.

## 구조

| 파일 | 역할 |
|---|---|
| `core.js` | 계산 규칙만 담당. 세트 나누기, 운동 목록(추가·수정·삭제·순서·체크), 운동 진행·되돌리기, 입력 보정, 저장값 검사 |
| `app.js` | 화면 3개(목록·운동 중·완료)와 효과. 계산은 모두 `core.js`에 맡김 |
| `styles.css` | 모양과 애니메이션 |
| `tests/core.test.js` | `core.js` 자동 검사 |

계산과 화면을 나눈 이유: 숫자가 맞는지는 브라우저 없이 `node`로 바로 검사할 수 있고, 화면을 바꿔도 계산 규칙이 깨지지 않음.

## 효과

- 카드: 누르는 순간 눌림, 완료 시 위로 날아가고 새 카드가 아래에서 튀어 오름
- 현재 횟수: 숫자가 올라가는 애니메이션, `+25` 같은 표시가 떠오름
- 운동 넘기기: 가로 스크롤 + scroll-snap. 가운데 운동은 크게, 양옆 운동은 작고 흐리게 살짝 보임
- 아래 탭: 운동별 진행 막대, 완료 시 ✓
- 진행 링과 세트 점, 완료 시 체크 표시와 색종이, 휴대폰 진동(지원 기기만)
- 기기의 "동작 줄이기" 설정이 켜져 있으면 움직임과 색종이를 끔

## 아이콘

덤벨 아이콘. 원본은 `icons/icon.svg` 하나이고, 홈 화면용 PNG(180·192·512px)는 이 파일로 만든 결과물.
SVG를 고친 뒤 아래 명령으로 PNG를 다시 만듦(Windows의 Microsoft Edge와 Pillow 필요).

```bash
python 10_RepCounter/tools/make_icons.py
```

| 파일 | 쓰는 곳 |
|---|---|
| `icons/icon.svg` | 브라우저 탭 아이콘, PNG 원본 |
| `icons/apple-touch-icon.png` (180) | iPhone 홈 화면 |
| `icons/icon-192.png`, `icon-512.png` | Android 홈 화면(`manifest.webmanifest`) |

홈 화면에서 열면 주소창 없이 앱처럼 전체 화면으로 열림.
이미 홈 화면에 추가했다면 아이콘이 바로 바뀌지 않을 수 있음. 지우고 다시 추가.

## 검사

```bash
node --test 10_RepCounter/tests/core.test.js 10_RepCounter/tests/icons.test.js
```

## 입력 보정 규칙

- 이름: 최대 20자. 비우면 "운동 N".
- 목표: 1~9999 정수. 숫자가 아니면 50.
- 세트 수: 1~50, 목표 이하 정수. 숫자가 아니면 5. 소수는 버림.

## 저장 형식

브라우저 저장소 키 `rep-counter:v2:library`(운동 목록), `rep-counter:v2:workout`(진행 중 운동).
이전 단일 운동 형식(`rep-counter:v1`)은 처음 열 때 삭제.
