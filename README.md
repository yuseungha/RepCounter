# 횟수 카운터 (10_RepCounter)

운동 횟수를 카드 단위로 세는 웹 앱. 목표 횟수와 카드당 횟수를 정하면 카드가 뜨고, 카드를 누를 때마다 그 숫자만큼 현재 횟수가 늘어남.

- 예: 목표 50, 카드당 10 → `10` 카드 5장. 다 누르면 50으로 완료.
- 나누어떨어지지 않으면 마지막 카드는 남은 수만 표시(55/10 → 10×5 + 5). 마지막 카드는 주황색.
- 되돌리기: 직전 카드 한 장 취소(PC는 Ctrl+Z도 가능).
- 진행 상황은 브라우저에 저장되어 새로고침·창 닫기 후에도 이어짐. "새로 시작"으로 초기화.

## 실행

### 휴대폰

주소: https://yuseungha.github.io/RepCounter/

GitHub Pages로 배포. PC가 꺼져 있어도 열림. 처음 한 번 홈 화면에 추가하면 앱처럼 실행 가능.

- iPhone(Safari): 공유 → 홈 화면에 추가
- Android(Chrome): ⋮ → 홈 화면에 추가

열 때 인터넷 연결 필요. 진행 상황은 휴대폰 브라우저에 저장되어 앱을 닫아도 유지.
`main`에 올리면 1~2분 뒤 같은 주소에 반영.

### PC

설치 없음. `index.html`을 브라우저로 열면 됨.

참고: 파일을 휴대폰에 복사해 여는 방식은 휴대폰 브라우저가 로컬 HTML·스크립트를 막는 경우가 많아 권장하지 않음.

## 구조

| 파일 | 역할 |
|---|---|
| `core.js` | 계산 규칙만 담당. 카드 숫자, 누적, 되돌리기, 잘못된 입력 보정, 저장값 검사 |
| `app.js` | 화면 그리기와 효과. 계산은 모두 `core.js`에 맡김 |
| `styles.css` | 모양과 애니메이션 |
| `tests/core.test.js` | `core.js` 자동 검사 |

계산과 화면을 나눈 이유: 숫자가 맞는지는 브라우저 없이 `node`로 바로 검사할 수 있고, 화면을 바꿔도 계산 규칙이 깨지지 않음.

## 효과

- 카드: 누르는 순간 눌림, 완료 시 위로 날아가고 새 카드가 아래에서 튀어 오름
- 현재 횟수: 숫자가 올라가는 애니메이션, `+10` 표시가 떠오름
- 진행 링과 세트 점, 완료 시 체크 표시와 색종이, 휴대폰 진동(지원 기기만)
- 기기의 "동작 줄이기" 설정이 켜져 있으면 움직임과 색종이를 끔

## 검사

```bash
node --test 10_RepCounter/tests/core.test.js
```

## 입력 보정 규칙

- 목표: 1~9999 정수. 비어 있거나 숫자가 아니면 50.
- 카드당 횟수: 1~목표 정수. 비어 있거나 숫자가 아니면 10. 소수는 버림.
